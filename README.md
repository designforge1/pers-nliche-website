# Persönliche Website &ndash; Sajad Ahmadi

Statische Website (reines HTML/CSS/JS, kein Build-Schritt nötig) zur Vorstellung von
Sajad Ahmadi als Immobilienmakler und Webdesigner.

## Struktur

- `index.html` &ndash; Startseite mit persönlicher Vorstellung und Links zu beiden Bereichen
- `immobilien.html` &ndash; Immobilienmakler-Bereich
- `webdesign.html` &ndash; Webdesign-Bereich
- `css/styles.css` &ndash; gemeinsames Stylesheet
- `js/main.js` &ndash; mobiles Navigationsmenü

## Lokal ansehen

Einfach `index.html` im Browser öffnen, oder z.B. mit einem einfachen lokalen Server:

```bash
npx serve .
```

## Hosting

Da es sich um eine rein statische Website handelt, kann der gesamte Ordner bei
jedem beliebigen Anbieter gehostet werden, z.B.:

- [Vercel](https://vercel.com) oder [Netlify](https://netlify.com) &ndash; Ordner per Drag &amp; Drop hochladen
- [GitHub Pages](https://pages.github.com) &ndash; Repository verbinden
- Klassisches Webhosting (z.B. IONOS, Strato) &ndash; Dateien per FTP hochladen

## Inhalte anpassen

Die Texte auf allen drei Seiten sind aktuell Platzhalter und sollten mit echten
Inhalten (Fotos, Projektbeispiele, ausführlichere Texte) ersetzt werden.
